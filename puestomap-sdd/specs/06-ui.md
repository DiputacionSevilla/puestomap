# 06 — Interfaz de usuario

## 1. Principios
- Herramienta de trabajo para 2-3 personas: densidad de información alta, pocos clics, teclado.
- Tailwind + shadcn/ui. Tema claro y oscuro (según sistema). Español.
- Cada estado VNC tiene un color y **además** un icono/forma (accesibilidad):
  `READY` verde ●, `NOT_LISTENING` ámbar ▲, `NOT_INSTALLED` rojo ✕, `OFFLINE` gris ○, `UNKNOWN` gris discontinuo ◌.
- Atajo global `Ctrl+K`: buscador de equipos (hostname, IP, usuario) → Enter abre ficha;
  `Alt+Enter` lanza asistencia web del resultado seleccionado.

## 2. Estructura de navegación

Barra lateral: **Inicio**, **Equipos**, **Mapa**, **Sesiones**, **Estructura** (edificios,
plantas, departamentos, despachos), **Importar/Exportar**, **Ajustes** (OCS, sondeo,
credenciales VNC, usuarios — según rol), **Auditoría** (ADMIN), **Ayuda TightVNC**.
Cabecera: buscador global, indicador de última sincronización OCS / último sondeo, usuario.

## 3. Pantallas

| Ruta | Contenido clave |
|---|---|
| `/login` | Usuario, contraseña, mensaje de bloqueo |
| `/` | KPIs (tarjetas clicables), tabla por edificio, últimas sesiones, estado de sync |
| `/equipos` | Panel de filtros a la izquierda (colapsable), tabla a la derecha, acciones por fila, export CSV, selección múltiple para asignación masiva (ADMIN) |
| `/equipos/[id]` | Cabecera con hostname, estado, IP, último usuario y botones grandes "Asistencia" / "TightVNC" / "Comprobar ahora"; pestañas: Resumen, Ubicación (mini-plano), Hardware, Sesiones, Auditoría |
| `/mapa` | Selector edificio/planta arriba; plano a pantalla completa; leyenda y contadores; buscador; conmutador "Modo edición"; en edición, panel izquierdo "Sin ubicar"; panel derecho de detalle al seleccionar |
| `/remote/[computerId]` | Pantalla completa negra con barra superior: hostname · usuario · IP · cronómetro · estado · botones; zona noVNC |
| `/sesiones` | Activas arriba (con botón "Ir a ficha"), histórico abajo con filtros |
| `/estructura/...` | Tablas CRUD; en planta: subida de plano con vista previa y, opcionalmente, editor de rectángulos de despacho |
| `/importar` | Pestañas Equipos / Estructura: subir CSV → previsualización con errores por fila → confirmar; plantillas descargables |
| `/ajustes` | OCS (estado, última ejecución, "Sincronizar ahora", historial), Sondeo (parámetros leídos de env, solo lectura), Credenciales VNC, Usuarios |
| `/auditoria` | Tabla filtrable y exportable |
| `/ayuda/tightvnc` | Explicación del modo nativo y descarga de `extras` |

## 4. Mapa — detalle de comportamiento
- Leaflet `CRS.Simple`, `ImageOverlay` con bounds `[[0,0],[planHeight, planWidth]]`.
  Conversión: `lat = (1 - posY) * planHeight`, `lng = posX * planWidth` (encapsular en
  `toLatLng`/`fromLatLng` con tests).
- Marcadores `divIcon` (círculo 14-18 px con el color/forma del estado). Etiqueta de hostname
  visible con zoom ≥ umbral configurable.
- Arrastre desde la lista "Sin ubicar": HTML5 drag & drop sobre el contenedor del mapa,
  convertir coordenadas de pantalla con `map.mouseEventToLatLng`.
- Resaltado de foco: anillo pulsante 3 s y `flyTo`.
- Si la planta no tiene plano: mensaje con enlace a subirlo (ADMIN) y lista de equipos de la planta.

## 5. Mensajes de error de asistencia (RF-06 CA-5)

| Situación | Mensaje |
|---|---|
| 4401 / token caducado | "La autorización de conexión ha caducado. Reintentar." |
| 4409 | "Esta autorización ya se utilizó. Reintentar." |
| 4403 destino | "La IP del equipo no está en la red permitida para asistencia." |
| 4502 refused | "El equipo responde pero TightVNC no acepta conexiones (servicio parado o firewall)." |
| 4502 timeout | "El equipo no responde (apagado o fuera de la red)." |
| `securityfailure` | "Contraseña VNC incorrecta. Revisa la credencial asignada al equipo." |
| `SESSION_IN_USE` | "Juan está conectado a este equipo desde las 10:42. ¿Conectar igualmente?" |
